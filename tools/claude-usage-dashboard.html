Cache read defaults to 0.1× input; cache write to 1.25× input (5-min cache). Override any cell. Pricing is cached from current public Claude rates — adjust if Anthropic changes them.

Why this isn't fully automatic: Anthropic only exposes per-day spend/token data through the Admin API, which requires an organization on API/Console billing. Subscription plans (Pro/Max/Team) have no such API, so usage is logged manually here. The "equivalent API cost" is what the same tokens would cost on the pay-as-you-go API — a proxy for value, not your actual subscription charge (that's the fixed monthly fee in Settings).
